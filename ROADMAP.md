# Roadmap

Backchannel is an alpha project. The roadmap favors safe capture, faithful inspection, and a stable local workflow over broad feature count.

## Near Term

- Add configurable capture redaction policies without changing raw-capture behavior silently
- Improve capture retention controls, storage visibility, and deletion workflows
- Expand accessibility and responsive coverage for dense flow inspection
- Harden process lifecycle behavior and recovery after interrupted sessions
- Publish reproducible release artifacts with provenance and checksums

## Later

- Improve WebSocket and HTTP/2 inspection fidelity
- Add extension points for custom decoders
- Expand HAR import and export support in the dashboard
- Improve Android connection guidance and certificate cleanup
- Add opt-in structured analysis workflows with explicit data-disclosure boundaries

Feature requests and proposals belong in GitHub issues. Security-sensitive ideas or reports should follow [SECURITY.md](SECURITY.md).
